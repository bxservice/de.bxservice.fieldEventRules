# CLAUDE.md — iDempiere Field Event Rules Plugin

## What this project is

An iDempiere OSGI plugin that lets implementers define "when field X changes,
do Y" entirely inside the Application Dictionary — no Java, no IDE, no external
tooling required. Think of it as form events + simple actions, configurable by
power users and implementers rather than developers.

The plugin adds a first-class AD concept called a **Field Event Rule**: a
structured record that says "on this trigger, if this condition is true, apply
these actions (set fields / validate data)". Rules execute both at the UI level
(callout path) and at the model level (before-save), so data consequences are
consistent whether a record is created through a window, a process, an import,
or the API.
